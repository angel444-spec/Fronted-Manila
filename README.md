# MANILA 

**MANILA** es una página web gastronómica desarrollada en **Angular**, diseñada para ofrecer una experiencia interactiva y dinámica a los usuarios que desean explorar diferentes opciones de comidas y bebidas.

La plataforma permite consultar información de productos, conocer sus ingredientes, realizar búsquedas, aplicar filtros, gestionar pedidos y generar comprobantes en formato PDF. Además, cuenta con un diseño moderno, adaptable a diferentes dispositivos y un juego interactivo relacionado con la gastronomía.

---

## Características principales

- **Exploración de comidas:** Visualización de diferentes platos gastronómicos.
- **Exploración de bebidas:** Consulta de diferentes bebidas y cócteles.
- **Búsqueda de productos:** Búsqueda de comidas y bebidas por nombre o ingredientes.
- **Filtros dinámicos:** Clasificación de productos según sus categorías.
- **Gestión de pedidos:** Selección y administración de productos para realizar pedidos.
- **Comprobantes PDF:** Generación de comprobantes de pedidos en formato PDF.
- **Juego interactivo:** Actividad de entretenimiento basada en encontrar imágenes de comidas y bebidas.
- **Diseño adaptable:** Interfaz responsive para diferentes tamaños de pantalla.
- **Diseño moderno:** Interfaz visual con una identidad gastronómica propia de MANILA.

## APIs utilizadas

El proyecto utiliza servicios externos para consultar información gastronómica:

- **TheMealDB:** API para obtener información de comidas, categorías e ingredientes.
- **TheCocktailDB:** API para consultar bebidas, cócteles e ingredientes.

## Instalación y ejecución

Para ejecutar MANILA de manera local, sigue estos pasos:

**1. Clonar el repositorio**

```bash
git clone URL_DE_TU_REPOSITORIO
```

**2. Ingresar a la carpeta del proyecto**

```bash
cd MANILA
```

**3. Instalar las dependencias**

```bash
npm install
```

**4. Ejecutar el servidor de desarrollo**

```bash
ng serve
```

**5. Abrir el proyecto**

Ingresa desde tu navegador a:

```text
http://localhost:4200/
```
